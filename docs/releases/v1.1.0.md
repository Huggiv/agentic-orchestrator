# Release v1.1.0

Release date: 2026-07-03

## Highlights

- Chat has moved to a session-first API model with persisted server-side context.
- Legacy chat endpoints were removed after hard cutover.
- Chat UI now surfaces session metadata for clearer Copilot-like continuity.

## Included Changes

### Backend

- Added session chat APIs for create/list/get/messages/prepare-trigger/confirm-trigger/archive.
- Added chat session and message persistence in SQLite via HistoryStore.
- Removed legacy chat routes:
  - POST /api/chat/message
  - POST /api/chat/message/stream
  - POST /api/chat/confirm
  - POST /api/chat/grooming/assign

### Frontend

- ChatConsole now uses session APIs for message handling and trigger confirmation.
- Added session metadata display in chat sidebar:
  - Open/Closed status badge
  - Trigger state label
  - Last updated indicator
- Removed legacy compatibility paths tied to deprecated routes.

### Documentation

- Updated README API section with session-first chat routes and examples.
- Updated project summary with chat architecture and API contract additions.
- Updated changelog with v1.1.0 notes and legacy endpoint removal details.

## Notes

- This release formalizes the chat hard cutover to session-first APIs and removes old compatibility behavior.
- Existing orchestration and Jira route contracts remain unchanged.
